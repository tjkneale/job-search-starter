# Networking email

Use the actual relationship, recipient's supported experience, and candidate's narrow and broader learning interest. Ask only for missing facts that materially change the draft. Do not invent a shared school, former employer, endorsement, or introduction.

This starter uses six concise drafting checks inspired by *The 2-Hour Job Search*: keep the message under 75 words; seek insight/advice; open with the verified relationship; ask a direct question; name both a specific topic and broader area; and devote most of the message to the recipient's relevant experience. The user can choose a different voice or format.

Give a useful subject and reviewable body. Check word count and that personal details are supported. Save a draft only when requested or useful for later work. A draft, recipient research, or known relationship does not authorize sending. See [the invented request](../../examples/networking/request.md). Hiring-team application messages follow the application-package workflow instead.
