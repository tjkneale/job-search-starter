# Search review

Read the candidate's criteria, current canonical roles, recent reactions, existing prep/packages, and supported follow-ups. Use scoped calendar/correspondence access only under the relevant authorization. Review the requested pursuits; this is not automatically a fresh discovery task.

Identify useful candidate decisions, real deadlines, time-sensitive postings, preparation needs, and evidence gaps. Reverify an official posting when needed for imminent action. Distinguish employer deadlines from inferred urgency, candidate decisions from assistant recommendations, and actual activity from drafts or CRM positions. Urgency changes criteria only when the user directs it or a documented candidate gate applies.

Lead with up to three useful next actions, each with its reason, supported date or unknown timing, owner, and existing artifact/decision needed. Separate assistant work that can proceed from candidate actions. Save material new facts/decisions in canonical records; an unchanged routine review need not create another report.

If personal activity completeness is in scope, follow [the activity procedure](../activity-records.md) without assuming benefit rules. This workflow creates no schedule or external action. See [the fictional review](../../examples/research/search-review.md).
