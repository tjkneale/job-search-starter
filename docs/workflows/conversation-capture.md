# Conversation capture

Start from user-supplied notes, transcript, or completion confirmation. Establish actual date/timezone, participants, purpose, and provenance. An invitation or scheduled meeting is not completion evidence. Keep material missing facts pending and ask only what affects the record; transcripts may need consequential speaker/name corrections.

Use [the notes template](../../templates/conversation-notes.md). Separate contact-reported statements, candidate confirmations, interpretations, promises, and open questions. A promised referral remains a promise until evidenced completion.

Save a dated summary under `workspace/opportunities/conversations/`, linked from affected role/company records. Route company facts and mandate changes to their canonical briefs; new confirmed accomplishments to evidence/story records. Update a stage only when supported by actual activity or an explicit user stage instruction. Company-level contact does not establish contact for every requisition.

List follow-ups with owner, supported deadline, and authorization status. A proposed follow-up is not sent. Where activity maintenance is requested, record only personally completed source-backed actions under [the activity procedure](../activity-records.md). CRM logging requires its own authorization and must not schedule an invitation. See [the fictional capture](../../examples/opportunities/conversations/cedarline.md).
