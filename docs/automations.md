# Optional recurring work

This starter contains no active schedule or copied scheduler configuration. Schedules live in your assistant's app/account, not these files. Create one only when you ask for it, and choose a cadence, timezone, scope, destinations, and permitted writes appropriate to your search.

These prompts are starting points to paste into a scheduling conversation:

**Opportunity scan:** “Each weekday at my chosen time, follow the role-research workflow and my current criteria. Diversify discovery, verify current official employer postings, preserve closed history and my decisions, and save material changes in my private workspace. Report actionable new roles or meaningful changes. Do not apply, contact people, or write to a CRM.”

**Search review:** “Review existing pursuits using the search-review workflow. Notify me about meaningful changes, deadlines, needed preparation, or candidate decisions; stay quiet when nothing is actionable. Keep actual activities distinct from preparation. Do not perform fresh discovery unless I request it.”

**Activity maintenance:** “At the cadence I choose, review my private activity log for source-backed, personally completed activities and missing facts. Use the jurisdiction and requirements I have configured and verified. Ask only for material missing facts; drafts and assistant viewing do not count as my activity.”

A copied prompt supplies no connected-account authorization. Add specific permitted local changes or scoped account reads when setting up a schedule. If CRM writes are desired, define the field allowlist and ordering/lock policy first. Run one requested task successfully before scheduling it, and check actual executions rather than treating configured active status as proof of success.
