# Blank templates

Copy the relevant structure into your personal `workspace/` and fill or omit placeholders before treating the result as a completed record. Templates supply no candidate facts or approval. `job_search.py init` uses only the [blank workspace skeleton](workspace/README.md).

| New record | Template |
| --- | --- |
| Role | [Role brief](role-brief.md) |
| Employer | [Company brief](company-brief.md) |
| Conversation preparation | [Prep](conversation-prep.md) |
| Application package | [Manifest](application-package.md) |
| Interview story | [Story](interview-story.md) |
| Completed conversation | [Notes](conversation-notes.md) |
| Personal activity | [Log](activity-log.md) |
